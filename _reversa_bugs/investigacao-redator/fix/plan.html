BUG-20261019-1 Guardrail false positive: negrito confundido com lista factual

Causa raiz

writer.py:60 — Heurística sintática
60line.startswith(("-", "*"|"|"))

Uma linha iniciada com **Proposta didática:** começa com * (asterisk markdown para negrito). A heurística não faz classificação semântica entre fato e proposta didática.

Estado epistemológico: confirmed — reproduzido isoladamente com assert (starts_with_asterisk=True, has_substance=True, is_factual_candidate=True, rejected=True).

Defeito

Local onde APARECE: app/services/pipeline/writer.py:56-68

Local onde NASCEU: Design da heurística de validação — usa prefixos de Markdown para detectar listas/tabelas, sem distinguir negrito.

Estratégia mínima

  1. Detectar negrito markdown: linha que começa com * mas cujo segundo caractere também é * (**texto**) — não é lista.
  2. Detectar lista real: *- ou 1. ou - seguido de conteúdo.
  3. Mantida exigência de citação para listas/tabelas/prosa factuais.
  4. Não criar bypass genérico: negrito factual sem fonte continua negativo.

BUG-20261019-2 Rejeição incondicional de gap report sem evidência/link

Causa raiz

writer.py:38-48 — Evidence gating rígido
38if not text.strip() or not evidence: 39 raise RuntimeError("Writer cannot produce a report without evidence") 41if cited == 0: 42 raise RuntimeError("Writer produced report without source citations") 45if not linked_urls or not linked_urls.issubset(known_urls): 46 raise RuntimeError("Writer used uncollected citation URLs")

Rejeita qualquer saída sem evidence/links, mesmo que seja um relatório de lacuna válido (## Visão geral\nNenhuma evidência disponível...).

Estado epistemológico: supported — leitura direta do código + clareamento do usuário no diagnóstico.

Defeito

Onde APARECE: writer.py:38-48. Onde NASCEU: Design original exigiu citação global incondicional.

Estratégia mínima

  1. Separar dois casos: relatório de gap (sem evidence) vs relatório com evidence.
  2. Se not evidence e texto é um gap report válido (tem conteúdo, passa validate_report_quality): persistir com flag report_type: gap.
  3. Se evidence existe mas texto não tem links: sinalizar like citation_metrics.gap_report = true, não rejeitar.
  4. Mantida validação de URLs não coletadas (linhas 45-48) apenas quando houver links.
  5. Não inventar evidence/fatos.
