## Resumo Fato vs Hipótese
- **Fato**: A chave Jina está ausente (`""`) no banco de dados runtime.
- **Fato**: `JinaSerpClient("", timeout=30.0)` levanta `ValueError` de forma determinística sem I/O de rede.
- **Fato**: `app/briefing/router.py:150-151` converte `ValueError` do construtor SERP em HTTP 500 `"Erro interno ao gerar briefing"`.
- **Hipótese descartada**: Falha de timeout (timeout configurado como 30.0 válido), falha de auth LLM (o fluxo nem chegou na chamada ao LLM), falha no n8n (requisição HTTP POST atingiu o backend corretamente).
