# Bugs do Deep Research

> Registry canónico de defeitos do projeto Deep Research.

- **closure_policy**: `local-software` — bug resolvido quando testes de regressão passam (assumida pela rota expressa; confirme na primeira execução completa do `/reversa-debugger`).
- **layout**: cada contexto em `_reversa_bugs/<contexto>/` — contém `intake/`, `bugs/`, e em demanda `inspections/` e `generated/`.
- **schema**: `references/bug-schema.md` da skill `/reversa-debugger`.
